# AI Enterprise Workflow Capstone — Business Solution Deployment

An end-to-end **demonstration** of a country-level revenue prediction service using a reproducible **synthetic dataset**. The example is not trained on the course's real transaction data, and results must **not** be represented as real-world business performance. Replace the input with your authorized course dataset and re-run validation before submitting as your own completed capstone.

## Features

- Data ingestion function (`src/data.py`) with input validation and an `ALL` countries aggregate.
- Three models compared: dummy mean baseline, Ridge, and random forest.
- Chronological holdout validation (most recent 20% of months), MAE and RMSE reported.
- EDA time-series chart and baseline-comparison chart (`figures/`).
- Python HTTP API with per-country and `ALL` country prediction routes.
- `/metrics` endpoint for validation metrics and prediction request counts; logging is redirected to a temporary path during tests.
- Automated unit tests for ingestion, model, API, and logging.
- Dockerfile, test script, and GitHub Actions CI pipeline.

## Quick start (Python 3.11)

```bash
pip install -r requirements.txt
sh scripts/run_all.sh
python -m src.api
```

Sample endpoints:

```bash
curl 'http://localhost:5000/health'
curl 'http://localhost:5000/predict?country=Canada&date=2025-01-01'
curl 'http://localhost:5000/predict?country=ALL&date=2025-01-01'
curl 'http://localhost:5000/metrics'
```

For any supported country, pass the exact country name from the dataset, with spaces URL-encoded. Forecast dates must be the first day of a month.

## Docker

```bash
docker build -t ai-enterprise-capstone .
docker run --rm -p 5000:5000 ai-enterprise-capstone
```

The image generates the demo data, trains a model and runs all tests at build time. Prediction logs inside the container are ephemeral unless a volume is mounted.

## Input format

CSV columns: `country,date,revenue`. Dates may be daily; the ingestion function aggregates them to calendar months. `ALL` is reserved for the automatically created sum across countries. `scripts/generate_data.py` supplies synthetic data for reproducibility. To use a different dataset, place it at `data/demo_revenue.csv` and run the training and visualizations scripts individually (rather than `run_all.sh`, which regenerates demo data).

## Limitations

This repository is a runnable starter solution using synthetic illustrative observations. It does not reproduce an assigned real dataset, optimize a real forecasting problem, deploy to cloud hosting, demonstrate production drift alerting, or guarantee Docker compatibility on every host. Validate the requirements and integrate your own course work before claiming full completion.
